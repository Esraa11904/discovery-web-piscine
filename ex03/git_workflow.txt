The Daily Git Development Workflow:

1. Modifying Files (Working Directory)
   - Edit, create, or delete code/documents in your local project workspace.
   - Command: git status
     (Checks the status of your working tree and shows modified/untracked files)

2. Staging Changes (Staging Area)
   - Select and prepare modified files to be included in the next snapshot.
   - Command: git add <filename>   (or 'git add .' to stage all files)

3. Committing Changes (Local Repository)
   - Save a permanent snapshot of staged changes into the local git history.
   - Command: git commit -m "type: descriptive message"

4. Pushing Changes (Remote Repository)
   - Upload local commits to the remote GitHub repository.
   - Command: git push origin main

5. Updating Local Code
   - Fetch and merge the latest updates from the remote repository.
   - Command: git pull origin main
